# 甲壳虫 —— QQ 群运动数据机器人

一个长期在线的 QQ 群运动搭子，接入 Garmin / 高驰 COROS 运动平台，支持群内查询、排行播报、截图打卡、打卡体系（里程碑 / 礼物 / 抽奖 / 节日彩蛋），并用 Agnes AI 大模型做数据解读与运动问答。

## 功能特性

- **多平台接入（每用户独立绑定）**：Garmin（佳明）按成员私聊填账号密码；高驰 COROS 走官方 OAuth 私密授权（不顶掉手机 App）；其余无开放接口的 App 靠**截图 OCR** 自动记录。
- **数据查询**：今日 / 周数据 / 月数据 / 任意时间段汇总 / 逐日明细，含距离、配速、爬升、时长、消耗、心率、负荷、单次最长等。
- **三榜排行**：今日榜 / 周榜 / 月榜，每晚 23:00 自动播报（周日追加周榜、月末追加月榜）。
- **打卡体系**：累计打卡天数、里程碑彩蛋、第 100 天礼物（先到先得）、群抽奖、节日 + 特殊距离彩蛋，全部**条件触发、幂等、可泛化**；发「打卡」还能看到累计 / 本月天数与**下一个里程碑倒计时**。
- **AI 增强层（Agnes AI）**：总结 / 鼓励我 / 建议 / @我运动问答 / 打卡点评。**LLM 只做锦上添花**，未配 key 或调用失败一律降级到确定性模板文案，机器人照常可用。
- **活动播报（跑团日历）**：管理员私下维护跑团活动——每月末自动发下月「跑团日历」图（有活动的日期红圈标注 + 格内活动名），活动前一天 23:00 提醒。固定活动（每周三例训 16:00 / 每周五例跑 20:00，默认西北田径场）自动进日历，手动活动可覆盖、可取消某天固定活动。**命令对普通成员隐藏**。
- **群互动玩法**：抽奖、骰子、随机数、帮助菜单。

## 技术栈

NoneBot2 + OneBot v11（NapCat）· SQLAlchemy + SQLite · RapidOCR（本地识别）· Agnes AI（OpenAI 兼容）· Python 3.10+

## 快速开始（本地）

```bash
# 1. 创建虚拟环境并安装依赖
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -e .

# 2. 准备配置
copy .env.example .env          # Linux/macOS: cp .env.example .env
# 编辑 .env，至少把你的 QQ 号填到 SUPERUSERS（运动平台为成员自行绑定，无需填账号密码）

# 3. 启动 NapCat（见下），然后运行机器人
python bot.py                   # 或双击 启动机器人.bat
```

> 首次调用 OCR 时会初始化 RapidOCR 引擎（加载模型），稍慢属正常。

## NapCat 配置（协议端）

NapCat 负责登录 QQ 并通过反向 WebSocket 把消息推给机器人：

1. 下载 [NapCat](https://github.com/NapNeko/NapCatQQ)（Windows 或 Linux 版）。
2. 启动并扫码登录机器人 QQ 号。
3. 配置「网络设置」新增**反向 WebSocket**，地址填：`ws://127.0.0.1:8080/onebot/v11/ws`。
4. 保存后 NapCat 会主动连到机器人，`python bot.py` 收到连接即打通。

> 本机器人基于 NoneBot2 的 OneBot v11 适配器，理论上兼容任何 OneBot v11 协议端（NapCat / LLOneBot 等）。协议端请自行遵守相关平台与腾讯的服务条款。

## 运动平台接入

> 每个成员**独立绑定自己的账号**（按 QQ 号区分），凭据按 QQ 存于 `data/accounts/`，不在群里暴露。

### Garmin 佳明

- 无第三方 OAuth，只能邮箱密码登录：成员发「绑定 garmin」后，**私聊**机器人发「garmin绑定 邮箱 密码」。
- 中国区账号在 `.env` 设 `GARMIN_IS_CN=true`（非中国区 `false`）。
- 底层用 [`garminconnect`](https://pypi.org/project/garminconnect/) 库。

### 高驰 COROS

- 无需账号密码：成员发「绑定 coros」→ **私聊收到授权链接** → 浏览器完成 OAuth 授权（不顶掉手机 App）→ 回群里发「绑定确认」。
- 通过 COROS 官方接口读取全天指标；`.env` 设 `COROS_REGION=cn` 或 `us`。

### 其他平台（小米运动 / Zepp Life 等）

- 无官方个人数据接口，**不做云端接入**：直接发运动截图，机器人 OCR 识别并记入今日数据、累计里程与排行。

## AI 能力（Agnes AI，可选增强层）

在 `.env` 填 `LLM_API_KEY`（模型 `agnes-3.0-flash`）即可启用。设计上 LLM **只进增强层、不进核心数据链路**：

- OCR 识别、数据解析、排行聚合、平台同步全部走确定性代码；
- 只把「聚合后的数字」发给模型，不发送原始消息 / 截图 / 账号密码；
- 未配 key 或调用失败一律降级到模板文案，机器人照常可用。

底层走 OpenAI 兼容接口，改 `LLM_BASE_URL` + `LLM_MODEL` 即可换成任意 OpenAI 兼容服务。

## 打卡体系

机器人内置一套**数据驱动、可泛化**的打卡体系，统一按「有数据的天」计数：

- **打卡单位 = 天**：同一成员同一天多次运动 / 截图只算 1 天。
- **覆盖范围 = 绑定 + 截图**：绑定 Garmin/COROS 当天有平台数据即算；未绑定发截图算。
- **计数起点 = `SEMESTER_START`**（默认 `2026-09-20`，本学期开学日）：之前的记录不统计。

围绕累计打卡天数挂载了几类**条件触发、只触发指定次数**的彩蛋：

| 彩蛋 | 触发条件 | 触发次数 |
|---|---|---|
| 🎉 里程碑 | 累计打卡达 `10 / 66 / 88 / 99 / 100 / 200 / 300 / 365` 天 | 每个成员每个里程碑一次 |
| 🎁 第 100 天礼物 | 累计打卡首次达 100 天 | 全群先到先得 10 份，满额不再触发 |
| 🏆 群抽奖 | 全群累计打卡突破 `200 / 400` 天 | 每个阈值一次（每次抽 1 名，多打卡多票） |
| 🎊 节日 + 特殊距离 | 国庆 10.01km / 元旦 1.01km / 五一 5.01km / 六一 6.01km | 每个成员每年每个节日一次 |

- 所有触发幂等由 `checkin_state` 表保证，重复打卡 / 重复查询不会重复发彩蛋。
- 礼物在成员跨过 100 天时**自动领取**并通知管理员（团长）安排发货，无需手动领取。
- 加新彩蛋只需改 `app/services/checkin.py` 顶部的常量（`MILESTONES` / `GIFT_DAYS` / `LOTTERY_THRESHOLDS` / `FESTIVALS`），不改代码逻辑。

发「打卡」可随时查看自己的累计 / 本月打卡天数。

## 命令列表

命令默认**无需 `/` 前缀**（`COMMAND_START=["", "/"]`，两者兼容），所有命令在「帮助」菜单里都能查到。

### 数据查询

| 命令 | 说明 |
|---|---|
| `今日`（`步数` / `今日运动` / `运动`） | 查询今日运动数据（含累计里程、本学期打卡次数） |
| `周数据` / `月数据` | 查看个人周 / 月汇总（次数、跑量、爬升、负荷等） |
| `数据 9月` / `数据 近30天` | 查任意时间段汇总 |
| `历史 9月`（`明细` / `训练记录`） | 查逐日训练明细 |

### AI 解读

| 命令 | 说明 |
|---|---|
| `总结`（可加 `月`） | AI 把本周 / 本月数据说成人话 |
| `鼓励我` | AI 按你的数据来一句鼓励 |
| `建议`（可加 `月`） | AI 按你的周 / 月数据给训练建议 |
| `诊断`（可加 `5k 25:00`） | 训练负荷 / 恢复 / 配速趋势诊断；附比赛成绩解锁 VO₂max / 成绩预测 |
| `@我 + 问题` | 运动知识问答，也能自然语言查数据（如「我今天跑了多少」「这周排行」） |

### 排行与打卡

| 命令 | 说明 |
|---|---|
| `排行` / `周榜` / `月榜` | 查看今日 / 本周 / 本月运动三榜（月榜含运动天数排行） |
| `打卡`（`打卡天数` / `我的打卡`） | 查看累计 / 本月打卡天数 + 下一个里程碑倒计时 |

### 绑定与个人

| 命令 | 说明 |
|---|---|

|---|---|

|---|---|

## 定时任务

| 任务 | 时间 | 说明 |
|---|---|---|
| 每日排行播报 | 每天 23:00 | 播报前先清理过期明细 + 同步今日数据 + 检查群抽奖；周日追加周榜、月末追加月榜，分段独立发送 |
| 活动前一天提醒 | 每天 23:00（搭榜单播报） | 明天有手动活动则提醒「明天有活动 + 时间/地点」，逐活动幂等 |
| 跑团日历播报 | 每月末 23:00（搭榜单播报） | 生成并发送下月「跑团日历」图，同月只发一次 |

时间可在 `.env` 用 `BROADCAST_HOUR/BROADCAST_MINUTE` 调整。周榜/月榜由 `daily_record` 直接聚合，无需单独的周聚合任务。

| `GARMIN_IS_CN` | `true` | 佳明中国区开关 |
| `COROS_REGION` | `cn` | COROS 区域（cn / us） |

| `LLM_MODEL` | `agnes-3.0-flash` | 大模型名（OpenAI 兼容） |

## 数据与隐私

- 全部数据存于本机 `data/`（SQLite 数据库、成员凭据、收到的截图），不经过任何第三方服务器（AI 增强层除外，且只发送聚合后的数字）。
- 成员账号凭据按 QQ 号隔离存于 `data/accounts/`，且只在私聊中收集，绝不出现在群里；落盘前经 Fernet 加密。
- OCR 用本地 RapidOCR，图片不离开本机；发给 LLM 的只有聚合后的数字。
- `.env`、`data/` 已加入 `.gitignore`，不会随代码提交到仓库。**请勿将你的 `.env` 或 `data/` 上传到任何公开位置。**

## 部署到常开主机

小主机（NUC 类）低功耗适合 7×24 常开。

### 方案 A：Windows（已装 Windows 直接跑）

1. 装 Python 3.10+。
2. 同上「快速开始」装依赖、配 `.env`。
3. NapCat 用 Windows 版。
4. 用 [NSSM](https://nssm.cc/) 把 `python bot.py` 注册为 Windows 服务开机自启：
   ```
   nssm install JkcBot "C:\...\python.exe" "C:\...\bot.py"
   nssm start JkcBot
   ```

### 方案 B：Linux

1. 装 Python 3.10+，`pip install -e .`，配 `.env`。
2. NapCat 用 Linux 版。
3. 用 `screen` / `tmux` 或 `systemd` 常驻 `python bot.py`。

## 常见问题

- **查询报「尚未绑定 / 授权」**：该成员还没绑定，发「绑定 garmin」或「绑定 coros」走流程；其他平台直接发截图。
- **绑定后查不到数据**：确认运动 App 已把当天数据同步到云端；Garmin 中国区账号需 `GARMIN_IS_CN=true`。
- **发截图没反应**：表情包 / 缩略图（最长边 < 500px）会被自动跳过；确认发的是运动记录截图，而非统计/列表页。
- **`今日` 报错**：看终端日志，多半是平台 API 返回结构变化，需微调 `app/services/providers/` 下的字段映射。
- **AI 功能没生效**：检查 `.env` 的 `LLM_API_KEY` 是否填写、`LLM_MODEL` 是否为 `agnes-3.0-flash`；未填 key 时自动降级为模板文案，属正常行为。
